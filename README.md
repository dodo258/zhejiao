# 折角 · 网站

本地电子书阅读器「折角」(Zhejiao) 的官网，托管在 GitHub Pages：<https://dodo258.github.io/zhejiao/>

折角是一款干净的本地电子书阅读器：无需登录、没有广告、离线也能读，支持 TXT、EPUB 和漫画。

| 页面 | 地址 | 用途 |
|---|---|---|
| 首页 | [index.html](https://dodo258.github.io/zhejiao/) | App 简介 |
| 隐私政策 | [privacy.html](https://dodo258.github.io/zhejiao/privacy.html) | App Store「隐私政策网址」 |
| 支持与反馈 | [support.html](https://dodo258.github.io/zhejiao/support.html) | App Store「技术支持网址」 |

纯静态 HTML，没有构建步骤，推送到 `main` 后由 GitHub Pages 自动发布。

> 隐私政策和支持页的地址已经填进 App Store Connect，文件名和路径不要改。
